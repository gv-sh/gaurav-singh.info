Fractals are forms whose structure repeats across scales, and remarkably little code can generate very intricate ones. This workshop covered drawing fractals with code: dimensionality, self-similarity, and iterated function systems. It assumed some basic programming experience. Topics included the Hausdorff dimension, spatial homogeneity, iterated function systems, and the Mandelbrot and Julia sets. It suited anyone interested in mathematical visualisation, creative coding, generative art, and patterns in nature.

**Key references:** <span class="pub-title">The Fractal Geometry of Nature</span>. B. B. Mandelbrot. W. H. Freeman, 1982. <span class="pub-title">Fractals Everywhere</span>. M. F. Barnsley. Academic Press, 1988.
