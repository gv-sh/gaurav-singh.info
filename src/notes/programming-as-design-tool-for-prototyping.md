Co-facilitated with [Dr.Venkat Chilukuri](/notes/dr-venkat-chilukuri/). Programming is usually assumed to be a software engineer's job. This unit treats it as a design tool instead, a pencil for working with digital technologies. It introduces that idea and shows how to start using programming to build prototypes that communicate design ideas. It covers the fundamentals of computer programming.
