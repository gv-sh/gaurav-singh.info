This course was for art and design students who wanted to learn to code with Processing. Participants learned basic programming concepts and how to use Processing's IDE to make interactive graphics and animations. By the end they had written programs for interactive games and generative art, enough of a foundation to bring coding into their own practice.

**Key reference:** <span class="pub-title">Processing: A Programming Handbook for Visual Designers and Artists</span>. C. Reas, B. Fry. MIT Press, 2007.
